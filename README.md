# Robot Nav Survey

AMR、四足、輪足機器人導航與視覺的前沿論文整理，每週自動更新。

## 使用

- 每週由排程 agent 依 [CLAUDE.md](CLAUDE.md) 的規則搜尋新論文並開 PR，審過再 merge。
- 手動更新：在 repo 裡開 Claude Code，說「更新論文整理」。
